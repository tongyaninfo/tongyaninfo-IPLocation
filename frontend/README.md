# 公共查询站与管理后台前端目录

已初始化 React 19 + TypeScript + Vite + Ant Design 6，使用一个响应式工程分别提供公共首页与 `/console` 布局。依赖在 package.json 与 package-lock.json 精确锁定；需要 Node.js 24 或更高版本。

先读[根规则](../AGENTS.md)、[一期方案](../docs/spec/一期实施方案.md)、[查询合同](../docs/api/查询接口.md)和[目录规划](../docs/项目目录规划.md)。

| 目录 | 职责 |
| --- | --- |
| `src/pages/Home/` | 自动/手动查询、来源结果、API 用法、真实启用来源署名 |
| `src/pages/Console/` | 登录、看板、数据库版本/上传、访问/审计日志和白名单设置 |
| `src/App.tsx` | 公共站与后台入口、主题及控制台懒加载 |
| `src/components/` | 查询输入、来源卡片、图表、状态与上传组件 |
| `src/components/ProductFeedback/` | 公共访客反馈入口 |
| `src/services/ip-location/` | 本项目公开 API 请求 |
| `src/services/console/` | 本项目受保护管理 API |
| `src/models/`、`src/types/` | 状态及同步合同 |
| `src/utils/`、`src/styles/` | 公共函数和样式 |
| `public/` | 可公开资源，不能保存库文件或秘密 |
| `tests/` | 两套布局、响应式、错误、竞态和权限交互 |

首页识别到本次访问IP后默认填入查询框，IPv4/IPv6均按服务端返回值使用；如果用户已手动输入或清空，迟到的自动识别不会覆盖。点击“查询我的 IP”重新填入并查询当前访问地址。首页包含访客 IP、手动查询、逐源状态卡片、可复制 API 示例与实际参与查询来源的署名。HTTP 503 的业务响应保留 IP 和来源状态；较晚返回的旧查询不覆盖新查询。仅显示当前启用的来源卡片，未就绪但已启用的来源如实显示原因；数量与就绪计数按可见来源统计，停用来源不显示卡片或署名，旧查询结果不会将其重新带回。纯真数据中的area按“网络描述”展示，不将组织名称直接称为运营商；地区保留文件原文。纯真按启用状态显示用户指定的完整署名，即使未配置文件、无匹配或本次为特殊IP也保留，停用则隐藏。当前默认查询库为DB-IP City Lite（`dbip`），接口示例分为我的IP与指定IP两组，各组按后台数据库顺序展示已启用来源（包括启用但未就绪），纯真标签为“纯真CZ88”，公开编码及curl示例统一为`CZ88`（例如`?db=CZ88`）；旧`chunzhen`响应在请求封装边界兼容，页面只使用新编码。来源停用时其标签隐藏，若当前正在查看该来源则回到对应分组的默认标签；单源命令显式携带对应db。

命令示例按“我的 IP”和“查询指定 IP”上下分组，两组独立切换格式或来源。前者含“我的 IP”纯IP标签，JSON/XML/TXT、已启用来源和ALL命令均省略ip，由后端识别连接地址；后者以1.1.1.1为例，含JSON/XML/TXT、已启用来源和ALL。JSON/XML使用dbip，TXT保留db=all，ALL为db=all的JSON；来源按后台顺序显示，停用隐藏。停用当前选中来源时只将对应分组重置为默认标签，不影响另一组。

结构化查询统一使用根路径参数，例如`/?ip=1.1.1.1&db=all&format=txt`。省略`ip`时由后端识别当前连接地址，省略`format`默认JSON；无参浏览器首页及curl根路径纯IP保持原协议。页面自动查询发送`/?db=all&format=json`，手动查询发送`/?ip=<编码后的地址>&db=all&format=json`，请求和API示例复用同一个URL构造函数；带`&`的curl示例完整使用单引号包裹。后端旧`/search/{ip}`和`/api/ip/me`仍兼容，前端新请求不依赖旧路径。

纯真地区行将原文的`–`分隔符以` · `展示，例如`中国 · 安徽 · 蚌埠`；接口和数据文件保留原文，地区名称中的普通连字符及网络描述不替换。首页版本区按来源真实精度标注“数据日期”“文件构建时间”或“内容标识”，不把上传时间或文件mtime作为版本，不将MMDB/XDB构建时间误称为官方数据发布日期。

首页数据库卡片在地理位置、各查询字段及无结果说明后提供复制图标；单字段仅复制展示值。数据日期、文件构建时间、内容标识等版本行保留可见信息，取消独立复制入口。卡片右上角复制全部可见字段，按来源、状态、地址族、位置/查询值或状态说明、版本的页面顺序输出“字段名：值”，每行一个字段，最后统一追加“来源：https://ip.tongyaninfo.com”；成功、无匹配、特殊地址和未就绪均使用相同规则。缺失值保留“未提供”，值内部空白归一，查询中全部复制入口禁用，失败保留手动复制反馈。交互复用CopyButton，无新增第三方剪贴板依赖。

文件构建时间按北京时间（Asia/Shanghai）以`yyyy-MM-dd HH:mm:ss`显示，IPv4/IPv6复合版本分别格式化；接口仍返回原始带时区时间，纯真日期版本保持`yyyy-MM-dd`，不补造时分秒。

IPinfo Lite结果同步展示源内的大洲、ASN、AS组织与域名；新增字段仅在有值时显示，域名只作文本，不触发外部访问。源内没有省市或坐标时保持缺失，不使用其他来源补造。

公开首页提供 IP 查询、API 文档、MCP 接入说明与主题切换，不展示管理入口，也不请求后台访问门禁或业务数据。MCP说明包含公开 `/mcp` 地址、Streamable HTTP、无登录/Token与开放跨域、可复制配置和三个只读工具；自身IP说明指MCP客户端出口。管理员自行输入 `/console` 访问后台，后台路由和服务端访问保护继续生效。

首页页脚提供 [GitHub 仓库](https://github.com/tongyaninfo/tongyaninfo-IPLocation)与 [Issues 问题反馈](https://github.com/tongyaninfo/tongyaninfo-IPLocation/issues)，欢迎使用、提交代码与反馈。GitHub 图标复用现有 `Icon` 的单路径内联 SVG 和当前文字颜色，不增加外部图片、图标字体、依赖或自动请求；窄屏自然换行，外链在新标签页打开。

页脚右侧展示纯真授权支持致谢：“感谢纯真（CZ88.net）给予本项目的授权支持。”复用 `ProviderLogo` 的本地官方 Logo 与深蓝背板，Logo 和名称均链接纯真官网；手机布局换行显示，深浅主题沿用共用颜色。致谢随纯真启用状态展示，包括已启用但文件未就绪或查询失败的场景；停用时同步隐藏，原有完整数据署名保持。

首页首屏根据[公开仓库 README](https://github.com/tongyaninfo/tongyaninfo-IPLocation/blob/main/README.md)标明“开源的 IP 聚合查询工具”，说明打开即查、多来源对照、结果与接入说明复制，以及 HTTP 多格式接口与公开只读 MCP。保留“连接每个 IP，看见网络的更多信息”主标题，只将“连接每个 IP”设为辅色，不添加下划线；其余文案保持正常颜色。功能摘要同步突出多来源对照、复制与脚本/AI 接入；该文案描述现有工具能力，不表示站点内置 AI 模型或承诺智能体自动配置。页脚欢迎提交 Issue 与 Pull Request，两个入口使用相同的前置图标和文字槽位保持对齐。

本轮首页“添加远程MCP服务”区右上角增加复制完整说明按钮，hover提示原文为“复制这段内容到您的智能体中添加 MCP 服务”。复制说明包含服务名、公开URL、Streamable HTTP、无认证与JSON片段，可交给支持MCP配置的智能体；无法自动配置时，按实际客户端格式手工粘贴JSON，不承诺所有智能体自动配置。仍保留原JSON复制入口和懒加载/稳定锚点。

后台已接入同源 Cookie 管理员登录与退出。独立登录页为 `/console/login`，不包含管理侧栏、运行总览标题或后台占位数据；总览、数据库、访问记录、审计、设置仅在真实身份核验通过后显示。访问 `/console` 或管理子页时先请求 `/api/console/access`，已有管理员且尚未登录时取得防伪令牌并转到独立登录页；登录及退出后重新核验身份和令牌。登录成功返回原管理页，默认进入 `/console/overview`，退出后回到独立登录页；`returnTo` 仅允许现有管理页面的明确内部路径，其他值回到默认页，不支持站外跳转。页头名称来自服务端，不在本地模拟身份，不持久化密码或防伪令牌。

存储未启用或不可用、管理员尚未初始化、来源不允许分别在独立入口外壳显示真实状态。首位管理员通过受控服务器本地流程创建，前端不提供注册入口；来源或身份检查失败时不读取后台业务数据。五个管理页面现已接入受保护的业务接口，实际数据为空、不可用或读取失败分别显示，不展示演示数据。

前端不直连供应商，不保存密钥；所有后台入口由服务端白名单与身份校验。页面权限和前端路由不是访问控制边界。控制台代码独立输出到 `dist/assets/console-*.js`，服务端应同步保护这些专属资源；公共依赖和共用样式不含后台数据。

## 后台五个页面

以下五页之外，新增独立 **MCP调用审计** `/console/mcp-logs`：按时间、来源IP、工具、结果码和Trace ID筛选，稳定分页并展开受控协议上下文、查询参数、来源状态摘要及既有安全请求头。名称/版本标为客户端自报信息，缺少上下文保持“未采集”，URL和上下文纯文本展示。页面显示当前普通访问队列健康与采集缺口；普通保留天数设为0同时停止MCP新采集，历史暂留。该页仍需后台来源白名单及登录，公开MCP不开放日志读取。详细合同见[MCP接口](../docs/api/MCP接口.md)与[后台管理接口](../docs/api/后台管理接口.md)。

本轮MCP明细新增独立入参/出参JSON视图、已记录内容复制及清洗/截断状态，Captured区分真实JSON null与未采集，旧记录显示未采集而不是空对象；只展示后端有界脱敏快照，纯文本渲染，长JSON在容器内滚动，不能据此获取完整聊天或原始HTTP请求响应。运行总览新增MCP HTTP请求/定位工具请求曲线与独立汇总，读取后端 `mcpTotals / mcpTrend`，不从当前明细页拼造总数；定位工具请求包含参数/协议错误，不表示实际来源调用，HTTP错误与业务失败分开。

总览公共趋势及MCP趋势共用SVG十字线交互，鼠标/触屏下十字线连续跟随当前位置，轴读数表示当前X/Y坐标；数据提示则定位最近真实时间桶，显示Asia/Shanghai时间与两条曲线实际值，不将光标坐标冒充实际样本。键盘左右键、Home/End切换真实桶，Esc关闭提示；不补不存在的0值桶、不生成伪造插值作为数据提示。空数据、单点、实际时间窗与采集缺口继续保留，手机信息面板不造成页面溢出。

- **运行总览**：近24小时/7天的公共请求、首页HTML、纯IP及逻辑查询卡片，SVG访问趋势、错误率/延迟、来源就绪状态、当前进程采集健康和最近审计。统计说明保留实际窗口与采集缺口，不把请求次数称为人数。来源调用次数不在当前统计表中另造数据。
- **IP数据库**：按来源提供上移/下移及显式保存排序，包含停用来源；保存携带排序修订号，冲突保留未保存顺序并提示刷新。首页来源卡片、页脚署名同步遵循服务端来源顺序，纯真未就绪署名也在对应位置。逐源启停直接对应公共查询；停用默认来源时同时选择另一就绪来源。上传原始MMDB/XDB/DAT并显示传输进度，纯真DAT固定为IPv4；传输100%后等待服务端校验，成功后仍需显式激活。仅提交文件及地址族，执行格式、大小和可读取性的技术校验。普通启停只修改启用状态，未配置文件的来源也可启用并展示未就绪；默认来源与版本激活仍受技术就绪条件约束。历史许可字段不参与前端业务判断，不展示确认、待确认或人工处理等说明。版本、摘要及任务结果独立显示，不自动删除旧文件。
- **访问记录**：按来源IP、路由、数据库、状态、格式和时间筛选，服务端分页；列表显示请求路径摘要，展开查看path及查询参数全文、追踪标识、版本和取消状态。路径按纯文本展示，敏感参数值由后端脱敏，超限提示截断，历史未采集路径显示“未采集”。支持左右方向键切换上一页/下一页，页码受总页数限制；加载中、输入或需方向键的交互控件、修饰键组合、重复按键和已处理事件不触发翻页。展开详情继续显示已采集的User-Agent、Referer及其他白名单请求头，支持多值和截断提示；URL只作文本展示，不自动跳转。来源地址的国家、省、市及网络运营商由后台CZ88解析后显示，含状态和数据版本；特殊地址、不支持和未采集分别说明。查询目标可出现在请求路径中，不展示请求正文。
- **管理审计**：按操作者、动作、结果、TraceId和时间筛选，服务端分页并展示脱敏差异；审计保持只读。
- **系统设置**：编辑默认来源、查询超时/并发及管理白名单；显示当前可信连接IP，保存前服务端阻止自锁。可编辑日志保存天数（空=无限期、0=停止新增且历史暂留）、完整IP开关、新登录会话时长及队列目标容量（重启生效）。存储类型和代理运行状态只读，连接凭据与密钥不回传。

业务写入使用当前会话内存中的防伪令牌；收到401、403或防伪失效后重新核验并卸载旧业务页面。版本、状态及设置携带修订号，遇到冲突保留错误信息，刷新后重新编辑。旧读取响应不会覆盖新筛选，重复提交不会产生并行写入。前台后续查询会刷新来源状态，跟随后台启停/版本切换。

桌面采用侧栏、统计卡片和双列面板；手机导航横向滚动、卡片与设置降列，明细表独立横向滚动。页面改动应在真实浏览器中按电脑与手机宽度验证数据加载、页面宽度和实际布局；单元测试不代替视觉验收。

首页支持手机布局收缩、长 IPv6 换行回退和 16px 查询输入字号；手机来源摘要分行、版本说明换行，页头保留两行导航。已使用受控响应在 320～1512px 的多种宽度检查默认/手动查询、错误、部分结果、深色与 API 示例。

## 开发与验证

JavaScript/CSS 构建目标显式设为 Chrome 79，避免可选链、空值合并和逻辑赋值保留在入口或懒加载脚本中。主题脚本在Vite之后内联，因此源码也保持旧引擎可解析的语法。`scripts/verify-browser-target.mjs`在复制发布产物及更新latest前检查所有实际JS与HTML内联脚本，不兼容语法会停止构建；结果保存到构建报告的`browserTarget`。

样式按能力降级：缺失`:where`或逻辑布局属性时使用与Ant Design相同版本的CSS-in-JS兼容配置；Flex gap用真实布局测量，避免把Grid gap支持误当成Flex支持，缺失时补导航、查询按钮等核心间距。主题控件使用具名普通分组，避免Chrome79的fieldset flex布局限制。现代浏览器保持既有样式优先级及布局；没有引入整包运行时polyfill。配置依据为[Vite构建目标](https://vite.dev/config/build-options#build-target)和[Ant Design样式兼容](https://ant.design/docs/react/compatible-style/)。

已在独立 Chromium 79.0.3945.0 引擎及 Android UA 下验证首页、查询、浅深主题与两组命令；不代表实体安卓设备、系统证书或所有 WebView。

```sh
cd frontend
npm install --ignore-scripts
npm run dev
npm run check:build-deps
npm run typecheck
npm test
npm run build
```

开发地址为 `http://127.0.0.1:5173`；`/api`、`/search`及显式根查询参数请求代理至 `http://127.0.0.1:5080`，不主动添加访客转发头。根路径只要包含`ip`、`db`或`format`任一参数就转交后端，参数键大小写不敏感，空值和重复值也交由后端验证；无参首页及仅含`v`、`utm`等无关参数的根路径仍由Vite提供HTML。开发代理下识别到的地址可能是本机回环地址，不能据此声称已验收公网代理链。

`npm run build` 先检查依赖边界与类型，再由 [scripts/build.mjs](scripts/build.mjs) 将每次产物写入仓库根 `.local/frontend-builds/<唯一版本>/dist/`。构建完成后写入 `.local/frontend-build-latest.json`，其中 `distPath` 为本次可发布目录的绝对路径，同时保存本次文件清单及原始/Brotli/Gzip字节数。打包必须采用该新目录，不遍历累计旧资源的兼容目录。

构建会先运行 [check-build-dependencies.mjs](scripts/check-build-dependencies.mjs)，拒绝锁文件、npm 别名、依赖声明及本机嵌套安装目录中的 `@stagewise/toolbar`、`cfonts`，发布前再检查本次文本产物与 Brotli/Gzip 侧车。`npm run check:build-deps -- --lock-only` 仅验证锁文件，不代替实际安装树检查。本项目原本未引入这两个包，无需安装替代工具；此检查用于防止后续构建链重新引入，范围不等同于全部第三方许可证审计。

构建仍将本次文件复制到 `frontend/dist/`，供既有本机后端读取；该目录保留旧哈希文件，不执行任何删除。`emptyOutDir:false` 与 `copyPublicDir:false` 避免清理和整目录复制原始图片、说明文档；应用引用的图片由 Vite 输出为 `assets/<名称>-<内容哈希>.<格式>`。构建将 `public/theme-init.js` 的同一份可信代码直接内联到原有头部位置，仍早于应用执行，省去外部阻塞请求；源码包含任何大小写的 `</script` 片段时立即拒绝构建，不执行动态求值。构建报告以 `themeInline:true` 标记，不再输出外部主题脚本或侧车。`public/` 只作原图存档及开发阶段主题脚本来源，生产不发布其中的巨大原图和未用文件。

JS、CSS、SVG 以 Brotli 质量11及 Gzip 级别9生成 `.br`、`.gz` 侧车；至少节省128字节及5%才保留，图片不重复压缩。服务端须按 `Accept-Encoding` 协商侧车、保留原始内容类型并设置 `Vary: Accept-Encoding`；前端不把侧车路径写入页面。报告中的 Brotli/Gzip 总量为全部本次文件选择相应编码后的合计，不等同于首页加载量。后台和 API 示例保留懒加载；后台专属 chunk 继续采用 `console-*` 名称，仍须由后端白名单保护。

`styles/console.css` 只包含原有 `.console-*` 选择器及其断点、深色变体，由已懒加载的管理入口导入，生产输出 `assets/console-<哈希>.css`。公共品牌、来源标识、主题变量和共用辅助类保留在 `global.css`；混合选择器已逐项拆分，不能将整个公共主题块移入后台样式。

构建仅对已核验的 `@rc-component/form@1.8.6/es/index.js` 设置 `moduleSideEffects:false`，避免仅间接引用表单上下文时保留未使用的完整 Form 和校验器；不修改依赖文件、UI、主题或其他模块的副作用规则。入口路径由本机依赖解析，版本变化会停止构建，须重新核验再调整规则。当前应用未使用 Ant Design Form；后续实际接入时应同时验证默认 Form 的静态方法和真实表单行为。

前端开发服务器无参根路径提供 HTML，curl/wget 无参根路径纯 IP 的内容协商应通过后端地址验证；显式 `ip/db/format` 根查询可通过开发代理验证。

## 品牌与配色

纯真显示名统一由后端提供为“纯真 社区版”，公开编码仍为 CZ88；共用 Logo 及首页卡片标题以新标签打开已登记官网，保持原图片槽位和底部署名。IPinfo 运行时 SVG 必须保留与 viewBox 对应的根 width/height（240.67×78.52），否则 Chrome 79 在 picture/flex 的 auto 尺寸约束下会把已加载 SVG 布局成 0×0；仅给 HTML img 补尺寸无效。修改只增加 SVG 固有尺寸，不改路径/颜色，不转位图。

公共首页、独立登录页和管理控制台共用 `Brand` 组件，点击左上角 Logo 在当前标签页打开[通研官网](https://www.tongyaninfo.com/)。后台另设返回公共查询的链接。共用主题：主色 `#013187` 用于按钮、链接、重点文字和选中状态；辅色 `#EF8200` 用于导航指示、标题下划线及强调装饰。浅色背景上的正文保留深色，避免橙色文字对比度不足。查询成功、失败等状态仍使用对应的语义色。

首页、独立登录页及后台五页支持自动、浅色、深色三种模式，默认自动实时跟随系统。沿用官网太阳/月亮双图标交互：点击太阳固定浅色，点击月亮固定深色，再次点击当前模式恢复自动；按钮的无障碍名称和提示说明当前状态。用户偏好保存在当前来源的`localStorage`，同源标签页同步；浏览器拒绝存储时仍可在当前页面切换。不同来源各自保存，不向后台发送主题偏好。

`public/theme-init.js`在应用与样式绘制前恢复主题，`models/useTheme.tsx`负责运行时状态及监听释放；Ant Design同步切换深浅算法，原生表单、图表和页面通过语义颜色适配。深色采用官网的深蓝画布和浅蓝链接，首页接口示例选中标签使用辅色橙色`#EF8200`，与指示线一致。品牌原图用白底承托，保持图像颜色及比例。

主题实现由前端测试覆盖；页面改动应在真实浏览器中按电脑与手机宽度验证。

Logo 使用 tongyaninfo 品牌横版原图，原始副本保留在 [public/brand/tyinfo-logo-horizontal.png](public/brand/tyinfo-logo-horizontal.png)。运行时优先采用AVIF、保留WebP回退，均为等比衍生图，宽度分为168、264、336、396及[528px](src/assets/brand/tyinfo-logo-lh-528.avif)五档，使用 `srcset`、`sizes` 按实际布局和像素密度选图；最高档覆盖最大174px显示宽度的三倍像素密度。各档均从原图直接缩放，不二次压缩、不改变品牌图案、颜色、文字或3:1比例。顶端品牌使用 `loading="eager"` 与 `fetchPriority="high"` 优先加载，声明尺寸预留空间。

浏览器标签图标由同一品牌目录的竖版原图等比生成 [64×64 PNG favicon](src/assets/brand/favicon-64.png)，公开页、登录页和管理页共用，原始 [1254×1254副本](public/brand/tyinfo-logo-vertical.png)保留归档。构建时通过 Vite 生成内容指纹地址，不再将大原图用于 favicon。

六类数据库 Logo 保留[public/logos](public/logos/README.md)原图副本，运行时使用 [src/assets/logos](src/assets/logos) 内的优化衍生图，由共用`ProviderLogo`按来源编码映射。根据实际字节数保留更小的格式：IPinfo保留SVG，DB-IP、CZ88和IP2Location使用无损WebP；ip2region及MaxMind优先AVIF并保留WebP回退，MaxMind提供96/192/288档，按实际槽位和像素密度选择。来源图标使用 `loading="lazy"`、`decoding="async"`，首页来源卡片、后台总览及数据库管理复用同一套图片。横版图保持比例，DB-IP小位图不额外放大；纯真白色横版用深蓝底承托，其他正色Logo用白底保证深浅模式清晰。原始图形与颜色不改，不访问外部图片服务；停用来源仍遵循已有前台隐藏规则。

## 产品反馈

源码包含产品内“意见反馈”入口：可提交最多 2000 字说明、3 张经确认的最终截图及 3 段原始 WAV 录音（每段最长 3 分钟）。截图提供画笔、框、箭头和黑色遮挡，只上传最终图；录音没有 AI 转写或模型调用。浏览器经本产品同源 API 提交，安装标识与官网后台关联由产品后端完成。

反馈失败保留当前页面草稿，未知结果沿用原请求号与附件；刷新只恢复最小回执，不保存正文或媒体。单条回执可查询处理状态及公开回复，不提供按机器标识公开列出反馈。回执查询码只随 POST 正文发送，不进入地址栏；公共反馈回执只保存在当前标签会话，关闭标签或清理站点数据后会丢失，可主动复制自行保存。

反馈只在用户主动提交时经产品后端建立安装身份并发送请求，产品运行期间不自动上报心跳或统计信息。组件使用审阅后的本地源码副本，不新增 UI 依赖；浏览器不持有安装凭据。受控前端测试不能代替真实麦克风与摄像头设备验证，也不代表已部署生产。
