## 使用注意

- 仅用于**标识数据来源**（nominative use），不得修改图形、颜色与文字，不得暗示品牌方对本站的背书。
- 各 logo 的商标与著作权归对应公司所有；商用展示前请查阅各品牌的商标 / 品牌使用政策。
- DB-IP 官方无更大尺寸的横版位图，展示宽度建议不超过约 96 px，避免放大模糊。
- 纯真白色横版 logo 在浅色背景不可见，浅色场景请使用 `cz88-icon.png` 或加深色底。
- IPinfo 与 MaxMind 为 SVG 矢量文件，可无损缩放。
- 更新时从上述官方地址重新下载，并同步更新本表。
