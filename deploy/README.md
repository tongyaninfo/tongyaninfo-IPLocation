# 部署目录

本目录提供 IP 聚合查询的部署资源：Docker 编排与首次初始化 SQL。示例部署目标域名为 `ip.tongyaninfo.com`，实际部署时请替换为自有域名。

入口需同时满足：

- 浏览器首页使用 HTTPS；命令行访问根路径返回纯 IP。对省略协议的 `curl ip.tongyaninfo.com`，HTTP 根路径不能被无条件重定向成非 IP 正文，详见[查询合同](../docs/api/查询接口.md)。
- 所有访客自身响应 `no-store`，根路径按 Accept 协商并设置 `Vary`，不发生跨用户缓存。
- 后端入口受控，可信代理只允许实际地址或网段；`/console`、登录、后台专属资源及管理 API 均检查来源白名单。
- 数据库文件、索引、上传暂存、后台存储和私密配置独立持久化，原始库不作公开静态文件。
- 访问日志异步批量写入，暴露队列、丢弃、写入故障及最后成功时间；日志采集遵守配置的脱敏与留存范围。

## 安全提示

- DNS、证书、数据库结构、凭据与数据清理等生产操作，请由部署方按自身流程自行确认后执行。
- 任何情况下不要把数据库密码、管理员密码、会话密钥或数据源下载 Token 提交到 Git。
- 数据库结构变更前先备份，并确认迁移与幂等 SQL 一致；应用启动不会自动建库或迁移。
