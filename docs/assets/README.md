## 数据与脱敏方式

- 查询目标固定为公共 DNS 地址 `1.1.1.1`，结果由本机已配置的只读来源实际返回，不使用真实访客地址展示归属地。
- 截图前将“本次访问 IP”替换为明确的“访客 IP 已脱敏”提示，并隐藏该卡片的复制按钮；查询框及结果中的 `1.1.1.1` 为公开示例，无需遮盖。没有保存未脱敏的原始截图。
- 仅采集公共页面，不包含管理员、访问记录、MCP 调用明细、内网部署地址、私有文件路径、配置内容或凭据。浏览器地址栏不进入截图。
- 截图使用独立本机应用进程，显式关闭 PostgreSQL 持久化和访问记录；不登录后台，不修改来源配置或数据文件，不操作线上环境。
- 只允许本机页面资源加载；MCP 配置里的公网地址是公开产品入口，截图不建立真实远程 MCP 会话。

电脑宽度为 1440px，手机宽度为 430px；截图按内容延长采集区域。已检查两种宽度无页面横向溢出、无 JavaScript 页面错误，并人工查看三张图片的布局及可见内容。手机图为浏览器视口模拟，不代表真实手机设备验证。

截图中的就绪来源、查询结果、版本与时间只反映采集时的本机状态，不保证与线上状态相同，也不作为实时数据证明；地理信息是数据库推断，不代表精确位置。
