# 数据源与许可

核验日期：2026-11-03。以下记录官方资料与本项目的接入边界；不代表已经下载、接入或取得个别授权。数据源许可、解析器代码许可和本项目代码许可分别管理。

> 本仓库不包含任何 IP 数据库文件。使用者需自行从各来源获取数据，并自行确认其许可、署名与使用范围是否适用于自己的部署场景。

## 公开默认库与启用条件

- 公开默认库为 DB-IP City Lite（`dbip`），GeoLite2 默认停用，纯真 QQWry IPv4 DAT 适配器可用；停用来源的前台卡片、计数、署名和许可说明同步隐藏。停用为运行选择，不改写下表的官方许可事实。IP2Location 使用 DB11 IPv4 MMDB；ip2region 及 IPinfo Lite 双栈适配器可用，定制 Country 不启用。
- 各来源的启用由部署方操作，运行配置仅反映操作者启用选择，不能作为供应商另行授权的证据。
- 来源许可及署名适用性由使用者人工处理，上传不要求授权声明或由系统判断。系统仅检查文件的格式、结构、地址族、版本、摘要和可读性；文件上传成功不代表厂商授权，也不代表已激活。所有来源的启用、激活、默认库及查询均不检查兼容许可字段；托管来源标记 `licenseReviewMode=manual` 且不宣称系统已确认授权。数据库顺序由后台保存，首页卡片与署名同序。

## 署名与数据使用

DB-IP 在实际使用其结果的页面展示回链；IPinfo 在实际使用时展示来源及许可说明。[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 和 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 均允许商用，但仍有署名、许可链接、变更说明等条件；BY-SA 还涉及发布改编数据时的相同许可要求。不能把署名视为绕过其他条款的许可，也不直接推断整个应用代码必须开源。

页面展示的 IP2Location 署名原文如下，仅作为该来源的展示要求记录：

```html
通研信息 uses the IP2Location LITE database for <a href="https://lite.ip2location.com">IP geolocation</a>.
```

页面以真实 JSX 文字与链接展示上述原句，不使用 HTML 字符串注入。现行官方协议的指定署名链接为 `https://www.ip2location.com`，与上述原文不同；使用者启用该来源前应核对适用展示要求。署名本身不解除 §5(c) 的用途限制。

纯真来源启用即显示以下署名（包括未就绪），停用隐藏：

```html
<p>IP地址位置数据由<a href="https://www.cz88.net">纯真CZ88</a>提供支持</p>
```

## GeoLite 的旧版本边界（人工处理参考）

仅对 MaxMind GeoLite 来源，现行 EULA §6.3 要求及时使用新版，并从**新版数据库发布之日**起 30 天内停止使用并销毁旧版；不是从下载日算起，也不是所有 IP 库的统一保留期。许可终止另有立即销毁要求。GeoLite 不能用于定位特定家庭、个人或街道地址。

本项目不会因此自动删除任何现有文件；版本清单、停止使用及处置流程由部署方负责。系统不判断该条款是否满足，不根据数据库年龄自动停用。

## 接入与验收

每个托管数据版本保存来源、实际版本、文件格式、地址族、SHA-256、校验结果和激活状态；旧授权字段保留兼容，不要求上传声明或由系统判断；凭据不进入公开记录。数据文件留在仓库外受控目录，不放入源码、镜像或测试夹具公开分发。供应商书面授权证明属于人工材料，由部署方自行归档，不包含数据库文件或运行凭据，也不因此自动启用来源。

公开查询只输出单次结果与来源信息；批量导出、整库下载、跨来源合库再分发需另行核对条款。法律与商业条款可能变化，正式启用或变更用途时应复核当时官方条款和具体合同。

## 适配器与文件核验

适配器使用官方读取器：City 的定位国家不以注册国兜底，ISP/ASN 缺失不补造。首页对已启用且就绪来源持续显示署名和许可，即使本次地址是回环/私有地址。

- 数据文件以只读方式使用，不原地覆盖或修改；后台上传另建不可变托管副本。
- IP2Location 现使用 DB11 MMDB 只读读取器；旧 CSV 适配器与文件保留但不注册。MMDB 的 metadata `ip_version=6` 表示树的格式，不能据此宣称 IPv6 覆盖。
- CSV 本身无可靠官方发布日期；MMDB 版本来自文件 metadata 构建时间，不把构建时间当作供应商发布日期，也不使用文件 mtime 推断。
- 所有来源均由管理员控制启停，系统不作许可或数据年龄判断。

## 查询结果的语言

界面默认中文，GeoLite2 和当前 IP2Location MMDB 读取器均按 `zh-CN`、`en` 的顺序选择库内名称，其他语言原文仅作缺省回退。DB11 MMDB 通常有国家和省州中文，城市通常只有英文或拼音；换为 MMDB 不代表城市自动中文化。缺少译名时保留来源原文，不使用其他定位来源覆盖结果，也不硬编码个别示例地名。接口没有按浏览器语言自动切换或接收语言参数。

历史 DB11 CSV 直接保存国家、省州和城市的原始名称，`China · Anhui · Bengbu` 属于该格式中的原文。官方[在线 Web Service](https://www.ip2location.com/web-service/ip2location)的 `lang=zh-cn` 属于另一种在线产品，不能直接应用于本地文件。官方另提供[国家多语言字典](https://www.ip2location.com/free/country-multilingual)和[城市多语言字典](https://www.ip2location.com/free/city-multilingual)，完整城市中文化需另行取得相应字典并确认许可及匹配规则。本项目仅使用 MMDB 已包含的名称，未下载字典、接入在线服务或修改原库。
