# PostgreSQL 后台存储结构

后台使用独立 PostgreSQL 保存管理、审计与日志统计；IP 数据文件与索引保持独立文件卷。模型、日志存储及首个迁移/幂等 SQL 已实现，见 [SQL 交付](../../deploy/sql/README.md)。源码默认使用有界内存存储，显式配置连接字符串后才启用 PostgreSQL。

独立数据库 `iplocation`，业务 Schema 为 `iplocation`。普通主键 `bigint` 通过 `IIdService` / `YiteIdService` 使用本地 Yitter.IdGenerator 生成；HTTP TraceId 只作关联字段，分钟统计和来源激活使用明确自然键。这里不使用外部 idserver。

上传授权由使用者人工处理，不通过上传字段声明或系统校验。复用版本表现有字段，新记录 `LicenseConfirmed=false`、`LicenseEvidenceJson={"reviewMode":"manual","systemVerified":false}`；`Status=ready` 仅表示技术校验通过。托管活动版本对外增加可选 `licenseReviewMode=manual`，不因该布尔值为 false 阻断技术可用版本。所有来源的兼容许可字段均不参与资格判断；全来源展示顺序以 `SYSTEM_SETTING` 的 `provider.displayOrder` 数组及其 Revision 保存，无需新表。

公开只读 MCP 和后台调用审计方案：`ACCESS_LOG` 新增可空 `MCP_CONTEXT_JSON jsonb`，具体上下文合同见 [MCP 接口](../api/MCP接口.md) 和 [后台接口](../api/后台管理接口.md)。

## 表与主要字段

| 表 | 主要字段与约束 | 用途 |
| --- | --- | --- |
| `ADMIN_ACCOUNT` | Id、规范化账号（唯一）、显示名、密码散列、Enabled、SecurityVersion、CreatedAt/UpdatedAt | 管理员身份；不创建默认账号或明文密码 |
| `ADMIN_IP_ALLOWLIST` | Id、Network（PostgreSQL cidr）、Enabled、说明、创建/修改人及时间 | 精确 IP 归一为 /32 或 /128，保存允许网段 |
| `IP_DATABASE_VERSION` | Id、ProviderCode、版本标识、文件格式、地址族、SHA-256、大小、私有存储定位、官方发布信息、许可依据、状态、创建人/时间 | 不可变数据文件及校验状态；私有路径不对外展示 |
| `IP_DATABASE_ACTIVATION` | ProviderCode + AddressFamily（复合主键）、VersionId（外键）、Revision、UpdatedAt | 每来源每地址族唯一活动版本；双栈文件可由两条记录引用 |
| `DATABASE_UPLOAD_TASK` | Id、ProviderCode、状态、接收字节、文件摘要、VersionId、阶段、脱敏错误码、操作人、起止时间 | 上传、校验和建索引进度；不保存整库正文 |
| `ADMIN_AUDIT_EVENT` | Id、ActorId、可信来源、动作、目标标识、脱敏差异、结果、TraceId、OccurredAt | 关键管理操作可靠审计，控制读取权限 |
| `ACCESS_LOG` | Id、TraceId、OccurredAt、路由类别、方法、协议、格式、数据库标识、状态码、耗时、来源 IP（可按配置脱敏）、取消状态、可空 RequestHeadersJson、SourceLocationJson 及 McpContextJson | 后台批量写入公共访问明细及受控 MCP 上下文，不在纯 IP 请求内发号或写入；仅管理员读取 |
| `TRAFFIC_MINUTE_AGGREGATE` | UTC 分钟 + 路由类别 + 来源 + 格式等固定维度（复合键）、请求/成功/失败/无匹配计数、延迟直方图 | 分清客户端请求与来源调用，不存任意用户输入作维度 |
| `SYSTEM_SETTING` | Key（主键）、非敏感 JSON 值、Revision、修改人/时间 | 默认库、日志限额等；不保存明文 Token/密码 |

列名与类型在模型映射中显式固定，表、列及关键约束带中文注释。时间用 `timestamptz` 保存 UTC；供应商仅有日期的版本信息不强制补成精确时刻。来源 IP 使用 PostgreSQL `inet`，读取受后台白名单及管理员权限限制并配置保留期；开源默认 `RetainFullSourceIp=false`，按网段脱敏后保存。

## 一致性与索引

- 规范化账号、来源激活键及设置键唯一；关系用正式外键。后台账号禁用和白名单变更立即影响后续请求。
- 版本激活使用期望 Revision 和事务更新活动指针，并记录审计；文件和内存读取器切换通过明确状态恢复，不宣称文件操作与 SQL 事务天然原子。
- 常用索引按访问时间、路由类别、来源、审计时间/操作者、上传状态建立；不以尚未压测的规模引入分区或时序扩展。
- 访问消费者批量获取业务 ID、批量追加及汇总；日志存储故障不阻塞纯 IP 响应。重复批次需有稳定批次/事件标识，避免重试重复计数。
- 延迟采用可合并直方图或真实明细计算分位数，不存“平均 p95”。来源调用和请求计数分别维度化，聚合写入须幂等。
- 审计与受控变更在一致流程中提交。普通访问日志不能与管理审计共用可丢弃队列。

## 数据与凭据边界

IP 地理数据库和范围索引留在受控文件卷，不导入此后台存储；查询库与访问日志库故障分别处理。访问日志以可空 `REQUEST_HEADERS_JSON jsonb` 保存经过白名单过滤及长度限制的 User-Agent、Referer 等请求头快照；凭据头不记录，Referer/Origin 去除账户、查询串和片段。不保存任意完整请求头、请求体或供应商原始响应。来源 IP 定位另以 `SOURCE_LOCATION_JSON` 可空 jsonb 保存 CZ88 后台解析的国家、省、市、网络描述、状态、原文和版本，不使用查询目标；旧记录不回填。

请求路径记录复用 `REQUEST_HEADERS_JSON` 元数据结构，加入 `requestPath / requestPathTruncated`，保留非敏感参数顺序、重复项和原始转义，敏感参数值脱敏；路径按 JSON 编码后 32 KiB 限额，请求头独立保持 8 KiB 预算。查询目标 IP 可随路径保存，历史缺失路径保持 null，不推测或回填；该扩展不改变表结构、索引、稳定事件键或分钟聚合维度，也不扩大公共路由采集范围。后台读取 DTO 以顶层同名字段提供路径及截断状态，详情纯文本展示。

MCP 调用审计是查询目标记录的明确例外：在 `MCP_CONTEXT_JSON` 保存规范化单 IP 及受控来源参数、协议方法/版本/请求 ID、客户端自报信息、业务结果和最多 6 项来源摘要。`input / output` 快照有界、脱敏并带各自截断标记，输入 8 KiB、输出 32 KiB、总上下文 48 KiB，敏感 key 脱敏并排除 `_meta`，读写均清洗；工具 input 为实收 arguments，其他方法为 params，可保留有界无效参数文本，标量 IP 仍合法规范化。output 为实际 result/error 内容，优先 structuredContent 并去重等价文本，不保存凭据、聊天历史、完整原始 HTTP 请求/响应。该内容扩展复用既有 jsonb 列，无 DDL 或迁移。普通 HTTP 访问可记录带查询目标的请求路径，仍不采集请求体或原始出参。MCP 沿用普通访问队列与保留设置，`0` 停采且不捕获 payload，旧记录新增字段为 null，不回填或物理删除。

数据库密码、管理员密码、供应商 Token 等认证材料不在本文件及代码中提供。Compose 模板引用外部提供的环境变量或密码文件，不启动即不会产生数据卷或角色。

普通 Web 启动不自动建库或迁移；自动删除、保留期清理及任何实际文件删除由部署方按自身策略决定。新环境的结构与凭据操作需部署方自行确认。
